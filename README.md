# 💸 FinTech Flutter App

A modern **FinTech Mobile UI** built with Flutter featuring:

* Animated fintech dashboard
* Wise-inspired custom credit card
* Floating modern navigation bar
* Advanced statistics & analytics page
* Crypto + investment wallet
* Beautiful profile dashboard
* Smooth animations & premium UI design

---

* Animated premium debit/credit card

# 🛠 Installation

## 1️⃣ Clone the repository

```bash
git clone https://github.com/yourusername/fintech-flutter-app.git
```

---

## 2️⃣ Navigate to project folder

```bash
cd fintech-flutter-app
```

---

## 3️⃣ Install dependencies

```bash
flutter pub get
```

---

## 4️⃣ Run the app

```bash
flutter run
```
